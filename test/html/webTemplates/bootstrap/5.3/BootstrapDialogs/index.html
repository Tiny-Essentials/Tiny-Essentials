BootstrapDialogs Test Environment

Drop-in replacement for alert(), confirm() and prompt() built on Bootstrap 5 modals.

💬 alert() Promise

Simple message with a single confirmation button.

❓ confirm() Promise

Resolves true on confirm and false on cancel, close or Esc.

⌨️ prompt() Promise

Resolves the input value, or null when cancelled.

⏳ showLoading() void

Non-dismissible overlay. Calling it again updates the current message.

🧪 Edge cases

Nested calls, HTML injection and body cleanup.

🎨 Global config

Mutates BootstrapDialogs.defaultConfig for every dialog.
