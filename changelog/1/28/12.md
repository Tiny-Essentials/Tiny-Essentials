## ✨ New Features

- **Added `getUserTimeFormat()`**: A new utility function that detects the user's preferred time cycle (12-hour vs 24-hour) based on their system locale. This allows for more personalized and localized time displays in your applications.

## 📝 Documentation Improvements

- **Fixed `getTimeDuration` jsDoc**: Updated the documentation for `getTimeDuration` to explicitly and accurately state that the function returns a `number`.
