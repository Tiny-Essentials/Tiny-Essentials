### 🔍 What’s New?
We have introduced a new property called `_fetch_data` within `MediaContentMetadata`.

### 🛠️ How it works
The `_fetch_data` property provides direct access to the **original, raw value** retrieved by `parseFile`. This allows you to see the data exactly as it was fetched, before any processing or sanitization occurs.

### ⚠️ Important: Developer Responsibility
Please note that this value is **pure and unvalidated**. 🛡️ 
* Because it bypasses our standard validation pipeline, the responsibility for implementing any necessary validation logic rests entirely with the developer if you choose to use these native values.

### ⚙️ Customization & Control
If you want to prevent this value from being populated, you can easily control it through `parseMediaMetadata`. 

If you require `_fetch_data` to return `null`, simply pass `null` to the `metadata` argument. 
> **Note:** Manual metadata overrides the automatic extraction process. 🔄
