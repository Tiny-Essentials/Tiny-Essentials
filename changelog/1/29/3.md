## 🚀 Main index fix

* **New exports in `src/v1/basics/index.mjs` and `src/v1/index.mjs`**: the HTML helpers from `basics/html.mjs` are now reachable straight from the package entry points.
  * **`trackFetchProgress`**: wraps a `Response` in a new one backed by a monitored `ReadableStream`, reporting `(loaded, total)` bytes through the `onProgress` callback. Accepts an optional `returnResponse` mapper to rebuild the `ResponseInit`.
  * **`fetchBlob`**: downloads a remote file as a `Blob`, with an optional `allowedMimeTypes` allow-list, native `fetch` options and an `onProgress` callback for download tracking.
  * **`loadImage`**: loads an image and resolves with a full `ImageLoadResult` (`element`, `event`, `status`, `isSuccess`, `loadTimeMs` and `dimensions`), normalizing success and failure into a single consistent shape.

## 🐛 Fixes

* **`TinyHtmlTemplate.toggleClass`**: the `force` argument is now honored, and the returned value matches the documented `boolean` contract instead of returning the instance.
