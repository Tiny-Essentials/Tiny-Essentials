## 🚀 New Features

* **Media Loader Suite**: A brand-new set of libraries dedicated to loading and caching media assets. 🎞️
  * **`TinyMediaLoader`**: The core loader for fetching media assets with progress tracking and cache support. 📦
  * **`TinyImageLoader`**: A specialized loader for images. 🖼️
  * **`TinyAudioLoader`**: A specialized loader for audio files. 🔊
  * **`TinyVideoLoader`**: A specialized loader for video files. 🎬
  * **`TinyMediaCache`**: A caching layer to avoid re-downloading media that was already loaded. 🗄️
  * **`TinyMediaProgress`**: A helper for tracking and reporting loading progress. 📊
