## Release Notes: Feature Expansion Update 🚀

Following our previous heavy maintenance update, which focused on stabilizing and repairing core module structures, we are excited to shift our focus toward delivering a massive wave of new features and enhancements!

### 🚀 Feature Updates

* **`TinyArrayComparator`**: Now features the ability to detect edited items within an array! To use this feature, simply specify the `idKey` option in the constructor to define the unique identifier for each element. 🔍

### 🚀 New Features
* **`TinyHtmlTagRegexBuilder`**: A powerful utility for constructing highly configurable and precise Regular Expressions to parse HTML tags and their specific attributes. 🏗️
* **`TinyRouter`**: A brand-new, pure JavaScript client-side routing system designed specifically for browser execution. 🗺️
* **`TinyMapCache`**: A new utility for managing temporary data using TTL (Time-To-Live) logic. ⏱️
* **`TinyServiceWorker`**: A dedicated script to simplify the implementation of Service Workers in your projects. 🛠️
* **`TinyCloner`**: A new class specialized in managing deep object cloning instances. 🧬
* **`TinySitemap`** and **`TinySiteMapStream`**: A new class added for sitemap management. 🗺️
* **`MediaValidator`**: A new utility suite for validating media file types (Video, Image, or Audio), featuring dedicated implementations for both Node.js and Browser environments. 🎞️
* **`TinyHttpResponseRegistry`**: Provides quick and easy access to HTTP error message information. ⚠️
* **`TinyURLSecurityVerifier`**: A tool to assist developers with URL security checks, featuring customizable verification rules and the ability to define insecure protocols. 🛡️
* **`TinyPasswordValidator`**: Your new dedicated helper for robust password validation. 🔐
* **`TinyPkgExportValidator.execCommandTester`**: A new function that facilitates the creation of quick code-testing commands. 🧪
* **`TinyUriParser`**: A versatile utility designed to parse various URI formats into structured objects and reconstruct them back into strings. 🧩
* **Regex Collection**: Added a comprehensive collection of Regex patterns for IPv4, IPv6, URLs, and login data. 🔍

### 🛠️ Improvements & Refactors
* **`BootstrapDialogs.showLoading`**: Now supports custom theme configuration. 🎨
* **`createSingletonTask`**: Enhanced with new monitoring configurations, allowing you to define whether the promise reset should be automatic or triggered manually. 🔄
* **`objType`**: 
    * Added native support for the `URL` type. 🔗
    * Added `getObjTypeOrder` to improve type management. 🔢
* **`browserDetector`**: 
    * Added the `isBrowser` and `isNode` utility. 🌐
    * Browser detection scripts now include safety checks for Node.js environments to prevent accidental execution outside the browser. 🛡️
* **`TinyI18`**: Improved jsDoc and added a new `acceptNullResults` option. 🌍
* **Renaming**: `getCheckObj` has been renamed to `getObjTypeRegistry` for better semantic clarity. 🏷️

### 🐛 Fixes & Documentation
* **`TinyMediaPlayer`**: Fixed jsDoc on line 42 (added the missing `Partial` type). 📝

### 🗑️ Deprecations & Removals
* Removed deprecated items: `diffStrings`, `getCheckObj`, and `static TinyTimeout.waitForTrue`.

### 📦 Ecosystem & Tools
* **Vite Plugin**: Added a new plugin to facilitate Service Worker installation within Vite projects. ⚡
* **GitHub Pages Support**: Added a new storage tool specifically optimized for Vite deployment on GitHub Pages. 🚀
