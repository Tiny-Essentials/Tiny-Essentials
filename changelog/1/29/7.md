## 🎬 YouTube embed fix

- 🎥 **`YoutubeMediaAdapter` — new `origin` option** — the embed URL now accepts an `origin` option, defaulting to `window.location.origin`. Without it the embedded player cannot validate the parent window and every `postMessage` call is rejected in production with _"The target origin provided ('https://www.youtube.com') does not match the recipient window's origin"_.

  ```javascript
  const adapter = new YoutubeMediaAdapter({
    videoId: 'dQw4w9WgXcQ',
    origin: 'https://example.com', // optional, defaults to window.location.origin
  });
  ```

## 🛠️ Internal

- 📦 **`express` removed** — the dev server no longer depends on Express. `test/express.mjs` was renamed to `test/dev-server.mjs` and now runs on top of `node:http` with a small Express-compatible layer (`createApp()`, `expressStatic()`, route matching, error middleware and the `req`/`res` helpers), dropping 726 lines from `package-lock.json`.
- 🙈 **`.npmignore`** — `.github` and `.vscode` are no longer published to the registry.
