## 🗂️ `webTemplates` are now self-contained projects

- 📦 **Dev Dependencies moved out of the root `package.json`** — `bootstrap`, `jquery`, `canvas`, `sharp`, `vite`, `ag-psd`, `marked`, `music-metadata`, `multiformats`, `file-type` and their `@types/*` packages are no longer installed by the root `npm install`. Each project inside `src/v1/webTemplates` now owns a `package.json` (and its own `node_modules`), so a template can bump or pin a dependency without affecting the library or the other templates.

## 🛠️ New build scripts

- 📥 **`npm run install:webTemplates`** — walks `src/v1/webTemplates`, finds every folder with a `package.json` and runs `npm install` inside it.
- 🧽 **`npm run clean:node_modules`** — removes every `node_modules` folder from a directory tree (defaults to `dist`). The build copies the templates into `dist`, and those dependencies must never be published.
- 🔐 **`npm run verify:hash`** — compares the hash of every file inside `dist` with a reference build and reports exactly which files differ, including the byte offset, line and column of the first difference.

  ```bash
  npm run verify:hash -- ../Tiny-Essentials-clone/dist --algorithm sha512
  ```

  Accepts `--dist`, `--algorithm`, `--ignore <glob>`, `--include-min-js`, `--concurrency`, `--context`, `--no-diff`, `--json` and `--quiet`, and exits with `0` only when every file is identical.
