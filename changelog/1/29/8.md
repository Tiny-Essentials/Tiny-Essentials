## 🎬 YouTube adapter: custom player options & flexible containers

- ⚙️ **`YoutubeMediaAdapter.playerOptions`** — new static getter/setter that customizes the initial values passed to every `new YT.Player(...)`. The adapter-controlled keys (`videoId`, `playerVars`, `events`) always take precedence, and custom `playerVars` are shallow-merged under the adapter's required vars.

  ```javascript
  YoutubeMediaAdapter.playerOptions = {
    playerVars: { modestbranding: 1, cc_lang_pref: 'pt' },
    host: 'https://www.youtube-nocookie.com',
  };
  ```

- 🧱 **Any `HTMLElement` as container** — `defaultContainer` now accepts any `HTMLElement` (not only an `<iframe>`), since the YouTube IFrame API replaces the target element with its own iframe. A new `YoutubeMediaAdapter.createContainer(options)` helper creates a plain `<div>` container.

  ```javascript
  YoutubeMediaAdapter.defaultContainer = YoutubeMediaAdapter.createContainer({
    id: 'youtubePlayer',
    hidden: true,
  });
  ```

- 🎨 **Simpler hidden styles** — both `createIframeContainer` and `createContainer` now apply lightweight inline styles (`pointer-events: none` + `background-color: #000`, plus `position: fixed` + `opacity: 0` when hidden) instead of the previous off-screen absolute positioning.

- 🐛 **Fix** — corrected the `YTPlayerOptions` typedef that was incorrectly aliased to `YTPlayerOptionsEvents`.
