## 🔓 `TinyUserActivationDetector.isUnlocked()`

- 🆕 **New static `isUnlocked()`** — returns `true` when a queued callback can run without waiting for a user activation. It is the negation of `hasUserActivation()`, except that a missing `navigator` (server-side rendering) is treated as **already unlocked**.

- ♻️ **Internal refactor** — the private `#unlocked` field is now initialized from `isUnlocked()`, so the server-side rule lives in a single place instead of being duplicated in the constructor.
- 📝 **Docs** — the JSDoc of the class no longer talks about "audio playback": the detector waits for a **document activation**, not only for audio permissions.

## 📦 New `regexp/Username/templates` entrypoint

- 🧩 **Barrel export** — the username templates can now be imported from a single path instead of one file per platform:

  ```javascript
  import {
    BlueSkyRegex,
    DiscordRegex,
    MatrixProtocolRegex,
  } from 'tiny-essentials/regexp/Username/templates';
  ```

  The individual entrypoints (`regexp/Username/templates/BlueSky`, `.../Discord`, `.../MatrixProtocol`) keep working exactly as before.
