## 🖱️ New `TinyUserActivationDetector`

- 🆕 **`TinyUserActivationDetector`** — queues callbacks until the browser reports a user activation, so media playback, fullscreen, clipboard and sensor calls are not silently rejected before the visitor interacts with the page. The activation is read from the sticky `navigator.userActivation.hasBeenActive`, so an interaction that happens before the first request is not lost.

  ```javascript
  import TinyUserActivationDetector from 'tiny-essentials/libs/utils/TinyUserActivationDetector';

  const detector = new TinyUserActivationDetector({ debugMode: false });

  // Runs immediately when the page is already active, or as soon as the
  // visitor interacts with it. The key deduplicates pending requests.
  detector.whenReady(() => audio.play(), 'main-audio');
  ```

  The class exposes `whenReady()`, `cancel()`, `unlock()`, `flush()`, `clear()` and `reset()`, plus the `size`, `autoKey`, `unlocked` and `existsTime` getters. It is also exported from the package root and ships with a dedicated browser test environment at `test/html/utils/TinyUserActivationDetector`.
