## ✨ What's New

- 🔎 **`TinyHtml.filter()`** — the static helper accepts a CSS selector, a DOM element, a list of elements or a predicate (`(index, element) => boolean`), and an optional `not` flag to invert the match. New instance counterparts `.filter()` and `.filterOnly()` were added as well.

  ```javascript
  TinyHtml.filter(document.querySelectorAll('li'), '.active');
  TinyHtml.filter(items, (i, el) => el.dataset.keep === '1');
  new TinyHtml(items).filter('.active');
  ```

- ⌨️ **`BootstrapDialogs` keyboard shortcuts** — dialogs can now be confirmed with <kbd>Enter</kbd> and cancelled with <kbd>Escape</kbd>, controlled by two new options.

  ```javascript
  await BootstrapDialogs.alert({
    title: 'Delete file?',
    closeOnEnter: true, // Enter confirms (default: true)
    closeOnEscape: false, // Escape is swallowed (default: true)
  });
  ```

  - 🛡️ `Enter` is ignored while composing IME text, on key repeat, inside `<textarea>` / `contenteditable` and when the focused element is a `<button>` (avoids double submits).
  - 🚪 `closeOnEscape: false` also disables Bootstrap's own `keyboard` dismissal, so the modal cannot be closed with <kbd>Esc</kbd>.

## 📝 Documentation

- 🏷️ **`HtmlElBoxSides`** — added a typedef description and documented the `left`, `right`, `top` and `bottom` properties, which were previously bare `@property` tags.
- 🧩 **`SetValueBase`, `GetValueTypes` and `SetValueList`** — the descriptions now sit above the `@typedef` tag instead of being glued to it, so they actually render as the type summary.
- 👁️ **`TinyHtml.tinyObserver`** — the static getter had no JSDoc at all; it is now documented.
- 🎣 **`_valHooks`** — documented every `get`/`set` pair for `option`, `select`, `radio` and `checkbox`, including their `@returns`.
- 🔬 **Internal helpers** — added descriptions to the nested `parseElement`, `createElement` and `mapArray` functions.
